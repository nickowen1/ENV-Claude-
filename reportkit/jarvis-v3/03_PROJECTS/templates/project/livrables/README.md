# Livrables

Ce dossier contient les fichiers produits pour ce projet (rapports, code, exports, etc.), datés si pertinent.

**Règle importante** : ce dossier est explicitement exclu du périmètre de `/snapshot` et `/rollback`. Un retour en arrière sur ce projet ne touche jamais son contenu — les livrables produits restent intacts quelle que soit l'opération de restauration effectuée sur le reste du dossier projet.
