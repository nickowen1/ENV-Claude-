# Automatisations

Ce dossier stocke les scripts, routines et intégrations créés au fil du temps.

**Règle d'activation** : toute automatisation créée ici est activée **manuellement** par Collins, à l'exception des routines de paramétrage système qui peuvent tourner automatiquement. Aucun script ne s'exécute de sa propre initiative sans déclenchement explicite.

- `scripts/` — scripts ponctuels
- `routines/` — routines répétées, incluant les routines de paramétrage à activation automatique
- `integrations/` — connexions avec des outils externes (n8n, etc.)
