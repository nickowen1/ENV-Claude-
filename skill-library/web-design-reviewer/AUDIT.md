# Audit — web-design-reviewer

**Origine** : externe.

**Résumé** : Skill de QA visuelle : navigue un site via un outil de browser automation (Playwright MCP recommandé), détecte les problèmes de layout/responsive/accessibilité/contraste via une checklist, corrige le code source (CSS/Tailwind/CSS-in-JS/Vue/Next.js), puis revérifie par capture d'écran.

**Sécurité** : Aucun appel réseau caché, aucune clé API, aucun script exécutable embarqué — uniquement de la documentation Markdown et des exemples de code CSS/JS illustratifs. Pas de risque d'exfiltration. Demande explicitement confirmation avant changements majeurs et limite les itérations à 3 avant de consulter l'utilisateur.

**Qualité/utilité** : Très bien structuré (workflow en 4 étapes, tableaux de sévérité, guide par framework, checklist WCAG détaillée), directement actionnable, aucune contradiction repérée. Dépend d'un outil de browser automation externe (Playwright MCP) à installer séparément, non fourni.

**Verdict** : VALIDÉ — documentation propre, sans risque de sécurité, bonnes pratiques de confirmation utilisateur intégrées.
